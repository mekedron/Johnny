- **Selfcheck pattern**: `python -m johnny.meet_worker.selfcheck` shells out to `pactl list short sinks/sources` (tab-separated; column 1 is the name) and verifies the expected names are present. Mockable with `unittest.mock.patch("subprocess.run")` for fast unit tests; runnable inside the container for an integration smoke test. Sink/source names overridable via `JOHNNY_SINK_NAME` / `JOHNNY_SOURCE_NAME` env vars so the same image can be reconfigured.
- **Audio bridge — parec/pacat over subprocess.PIPE**: `MeetAudioBridge` (`johnny/meet_worker/audio_bridge.py`) shells out to `parec --device=<sink>.monitor --rate=16000 --channels=1 --format=s16le --raw` for capture and `pacat --playback --device=<source>_loopback ...` for playback. Subprocess stdout/stdin are read/written via `loop.run_in_executor(None, fn, ...)` so the asyncio loop never blocks on the OS pipe. No external Python deps — keeps the meet-worker image free of numpy/scipy/audioop (latter is removed in 3.13).
- **Bounded asyncio queue with EOS sentinel + slot reserve**: For real-time capture, `asyncio.Queue(maxsize=N+1)` lets the producer always have room for a trailing `None` sentinel that signals EOF to the async-generator consumer. While streaming, the pump drops the oldest frame whenever `qsize() >= N` to keep latency bounded; on EOF, `put_nowait(None)` is wrapped in `suppress(QueueFull)` for defensive paranoia. Without the +1 reserve, the sentinel push would block forever when the queue is at user-facing capacity.
- **Resampling without numpy**: `resample_pcm16(pcm, src, dst)` uses `array.array("h")` + linear interpolation in pure Python. Adequate for sub-second 8k/16k/24k/48k voice chunks; not anti-aliased, so aggressive downsampling will alias HF content. For test correctness: a constant signal must round-trip exactly (`all(s == 1000)`); a 440 Hz sine at 48 kHz → 16 kHz preserves peak amplitude within ~10%; ramp signal preserves endpoints exactly.
- **Protocol-typed subprocess for testable I/O**: Defining a `_Process` `typing.Protocol` (`stdout: IO[bytes] | None`, `stdin: IO[bytes] | None`, `poll/terminate/kill/wait`) lets `subprocess.Popen[bytes]` satisfy the same shape as a `_FakeProcess` wrapping `io.BytesIO`. Override `_spawn_capture_process` / `_spawn_playback_process` in a `_FakeBridge` subclass to inject the fakes in tests — no `unittest.mock.patch` ceremony. Note: protocol-Attribute types are invariant in mypy strict — type the fake's `stdin: IO[bytes] | None` (not `_FakeStdin | None`) and `isinstance`-narrow in tests that need the subtype.
- **Provider ABCs — async generators declared on sync `def`**: Streaming ABC methods like `STTProvider.transcribe_stream` and `TTSProvider.synthesize_stream` are declared as `@abstractmethod def foo(...) -> AsyncIterator[T]: ...` (NOT `async def`). The signature returns `AsyncIterator[T]`; the implementor writes `async def foo(...)` with `yield` statements — the language transforms the body into an async-generator that *is* an `AsyncIterator[T]`. Declaring the base as `async def` would mark it a coroutine, not an iterator factory, and confuses both mypy and runtime semantics. `LLMProvider.chat`, by contrast, is `async def` because it returns a single coroutine resolving to `LLMResponse`.
- **`ruff B027` for intentional non-abstract ABC hooks**: When you want an empty default implementation in an ABC (e.g., `async def close(self) -> None:` as a hook subclasses *may* override), ruff flags it as B027 ("forgot @abstractmethod?"). Suppress with `# noqa: B027 — intentional non-abstract hook` rather than adding a `pass` (still empty) or making it abstract (forces every stateless adapter to write boilerplate).
- **Single-table sqlite fixture for ORM unit tests**: When only one or two tables need a real DB (e.g., `provider_credentials` for the loader tests) and other tables have backend-specific column types like `pgvector.Vector`, use `Base.metadata.create_all(engine, tables=[Model.__table__])` to create just the table(s) you need against in-memory sqlite. SQLAlchemy's `Model.__table__` is typed as `FromClause` in stubs but is `Table` at runtime — needs `# type: ignore[list-item]` on the `tables=[...]` arg under mypy strict. Pattern keeps DB-touching tests fast and dialect-portable.
- **Provider registry vs DB rows split**: `app.providers.base.ProviderRegistry` maps `(ProviderKind, name)` → factory. Adapter modules register their *factories* at import time; the registry knows nothing about credentials. The DB table `provider_credentials` says which providers are *active*. `load_active_providers(session)` (now in `app/providers/loader.py`) is the bridge — reads active rows, decrypts credentials, builds a `ProviderConfig`, and calls the registered factory. Unknown `provider_name` in the DB raises `UnknownProviderError` so misconfiguration fails fast at startup, not mid-meeting.

- **SAEnum `values_callable=` for StrEnum columns**: With `native_enum=False`, SQLAlchemy stores `.name` by default (uppercase). The hand-written migrations' `CHECK (kind IN ('stt', 'llm', 'tts'))` constraints use the lowercase StrEnum `.value`. Without `values_callable=lambda e: [m.value for m in e]` on every enum column, inserts fail in PostgreSQL with check-constraint violations. - **In-memory SQLite for FastAPI TestClient needs `StaticPool` + `check_same_thread=False`**: The TestClient runs each request on a worker thread; default SQLite connections are thread-bound. - **Partial unique index for "active per kind"**: `Index("uq_provider_credentials_active_per_kind", "kind", unique=True, postgresql_where=text("is_active"), sqlite_where=text("is_active"))` enforces "at most one active row per kind" at the DB level. - **Fernet at-rest encryption via `CredentialCrypto`**: `app/security/crypto.py` defines `CredentialCrypto(key)` with `encrypt(str) -> str` / `decrypt(str) -> str`. `get_crypto()` reads `Settings.fernet_key`. Capture path: `parec --device=<sink>.monitor --rate=16000 --channels=1 --format=s16le --raw` → blocking reads on a thread executor → bounded `asyncio.Queue` (maxsize = `queue_max_frames + 1` to reserve a slot for the EOS sentinel) → drop-oldest backpressure → `capture_frames()` async generator. Playback path: `play_frames(Iterable[bytes] | AsyncIterable[bytes], source_rate=None)` → optional `resample_pcm16` if `source_rate != sample_rate` → `pacat --playback --device=<source>_loopback ...` stdin via thread executor. Broken-pipe / OSError on writes is logged and swallowed (matches "survives transient underruns" AC). `__aenter__`/`__aexit__` for `async with` lifecycle; `stop()` cancels the pump, closes pacat stdin (signals EOS), and `terminate` → 2s wait → `kill` both procs.

- **Learnings:**
  - `audioop` is removed in Python 3.13. For sample-rate conversion in projects targeting 3.12+ that may upgrade later, prefer a pure-Python `array`-based linear interp or numpy. (Promoted to codebase pattern.)
  - mypy strict treats Protocol attribute types as invariant. `_FakeProcess.stdin: _FakeStdin | None` is rejected when the Protocol declares `IO[bytes] | None`, even though `_FakeStdin <: io.BytesIO <: IO[bytes]`. Fix: type the fake field as `IO[bytes] | None` and `isinstance`-narrow at the accessor. (Promoted.)
  - The trick of running the asyncio queue at `maxsize+1` to reserve a slot for the EOS sentinel keeps the drop-oldest semantics clean: producer keeps real-time frames at exactly `queue_max_frames` via `while qsize >= max: get_nowait()`, then the trailing `put_nowait(None)` always fits. (Promoted.)
  - `loop.run_in_executor(None, stdout.read, n)` on a `subprocess.Popen.stdout` is the canonical "non-blocking-ish read from a blocking pipe" pattern in asyncio. `asyncio.subprocess` is awkward when you also need `bufsize=0` and Unix-pipe semantics across both capture and playback in the same object.
  - ruff `UP041` strongly prefers builtin `TimeoutError` over `asyncio.TimeoutError` (which is just an alias since 3.11). Use `except TimeoutError` even in asyncio code.
  - `asyncio.Queue(maxsize=N)` can be safely created at `__init__` time in py3.10+ — no running loop required. Earlier versions tied queues to a specific loop at construction; that constraint is gone.
  - Initial implementation used a single `None`-sentinel push on EOS without reserving a slot. The drops-oldest-when-full test exposed the bug: with `queue_max=2` and 5 frames, the queue ends up at `[f4, f5]` (size = max), then trying `put(None)` blocked forever. Fixed by upsizing the internal queue by 1.
  - `_FakeStdin(io.BytesIO)` lets tests flip a `raise_on_write` flag to simulate broken-pipe mid-session; `super().write(b)` keeps the recording behavior in the OK path.
