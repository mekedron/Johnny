## Codebase Patterns (Study These First)

- **Backend layout**: `backend/app/` is the FastAPI application package (not `src/`).
  `app/main.py` defines the `app = FastAPI(...)` instance. Tests live in `backend/tests/`.
  PyProject uses `hatchling` build backend with `packages = ["app"]` because the layout
  is not the default `uv init --package` `src/<name>/` layout.
- **Backend tooling**: managed by `uv`. Quality gates from `backend/`:
  `uv run pytest`, `uv run ruff check`, `uv run mypy`. mypy runs in strict mode and
  has a relaxed override for `tests.*` (no decorator-typing requirement).
- **Frontend layout**: `frontend/` is a SvelteKit 2 / Svelte 5 (runes-mode) project
  scaffolded with `pnpm dlx sv create … --template minimal --types ts`.
  Root page is `frontend/src/routes/+page.svelte`.
- **Frontend tooling**: `pnpm typecheck` runs `svelte-kit sync && svelte-check`;
  `pnpm lint` runs `eslint .` (flat config in `eslint.config.js`).
  `@types/node` must be installed because the `.svelte-kit/tsconfig.json` generated by
  adapter-auto adds `"types": ["node"]`.
- **API base URL on the frontend**: read from `import.meta.env.VITE_API_BASE`
  with a fallback to `http://localhost:8000`. CORS on the backend allows
  `http://localhost:5173` for dev.

    `eslint-plugin-svelte`, `globals`, and `@eslint/js`, then add `eslint.config.js`.
  - Svelte 5 runes mode is enabled by default; use `$state(...)` rather than `let`
    reassignments for reactive fields in scripts.
